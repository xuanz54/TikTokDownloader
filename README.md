# 抖音数据采集台

抖音 / TikTok 数据采集网页工具。

## 功能

- **作品采集**：获取单个 / 批量作品数据
- **账号作品**：获取账号全部作品
- **合集作品**：获取合集全部作品
- **作品评论**：获取作品评论数据
- **账号详情**：获取账号详细资料
- **直播数据**：获取直播拉流地址
- **抖音热榜**：获取热搜榜单数据

## 使用

1. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```

2. 启动服务：
   ```bash
   python web_server.py
   ```
   或双击 `start_webui.bat`（Windows）

3. 浏览器访问 http://127.0.0.1:8080

## 配置

在网页「设置」Tab 中配置 Cookie 和代理，或手动编辑项目目录下的 `settings.json`。
